What I want to work on

Learning

RL for locomotion

Training control policies in simulation for legged and humanoid robots — whole-body skills, robustness to pushes and terrain, and getting them to survive the jump from sim to the real machine.

reward shaping · PPO · sim-to-real
Control

Model-based control & planning

MPC, optimal control and planning as the backbone a learned policy can lean on — blending guarantees from a model with the adaptability of learning.

MPC · LQR / DP · receding horizon
Interface

Human–robot interaction

Closing the loop back to the operator: EMG and intent, shared control, and force / haptic feedback in teleoperation — so a person and a robot form one stable loop.

EMG · shared control · bilateral teleop

Selected projects

Control

Inverted-pendulum control

Modelled the nonlinear dynamics and designed PID control via frequency-domain analysis (root locus, Bode), then pole placement and LQR to meet strict stability margins — with a Kalman filter rejecting sensor noise and disturbances.

PID · LQR · Kalman · MATLAB / Simulink
Robotics

Autonomous robots · CMU

Built several autonomous robotic systems across the stack: low-level PID and LQR control loops, odometry-based localization and path planning, and computer-vision / neural-network perception.

Python · Raspberry Pi · CV · CAD
Signals

Oscilloscope signal pipeline

Engineered a C and LabVIEW pipeline to extract oscilloscope traces from images and automate signal reconstruction, with a MATLAB algorithm for signal fitting and visualization.

C · LabVIEW · MATLAB
